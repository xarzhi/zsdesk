## 09:26 开机自启改为静默启动（--silent）

- 需求：登录 Windows 时不要弹窗口，后台待命，Win+E / 打开文件夹时才显示。
- 实现链路：
  - `app.rs`：新增 `--silent`（`Options.silent`）。只允许「纯窗口启动」组合，与
    `--new-window`/目标路径/`--win-e`/`--focus-search`/后台搜索同时出现直接 bail，
    避免请求被静默吞掉。参数透传 `window::run(..., silent)`。
  - `window/mod.rs`：`WindowState.silent` 字段；`run_inner` 里 `if !silent { ShowWindow }`，
    窗口建好但不显示（`ZSDesk.PreferredShow` 属性仍在，激活时按保存的普通/最大化显示）。
  - `navigation.rs::open_requested`：silent 窗口收到第一个打开请求就**接管**——清 silent、
    激活、把该文件夹导航到当前标签（single_tab 模式先 truncate 到 1 个标签），
    否则会出现「一个隐藏窗口 + 一个可见新窗口」。
  - `instance.rs`：拆出 `send_open`；新增 `adopt_hidden(profile,target,selection)`，
    找同 profile 的**不可见**窗口：有目标就发 OPEN_MAGIC 接管，没目标就 request_activation 显示。
    `app.rs` 在 claim/enter 之前调用它（`!new_window && !silent`）。
  - `quick_search/control.rs`：登录项命令改为 `"exe" --silent --profile-dir "..."`；
    新增 `previous_command`（旧的无 --silent 版本），`set_enabled`/`uninstall_owned`
    把它当作「自己的旧条目」先删再写，旧安装无需手动关开自启即可自动升级。
  - 文案：设置里「开机自启」说明改为「登录 Windows 时在后台就绪，不弹出窗口」；
    启动菜单项/提示同步改。
- 真机验证（23H2，装到 D:/Program Files\ZSDesk）：
  - `--silent` 启动 → 1 个窗口、`IsWindowVisible=false`、进程存活；
  - HKCU Run 自动从 `--profile-dir ...` 迁移成 `--silent --profile-dir ...`；
  - 再 `ZSDesk.exe C:/Windows` → 仍是同一个窗口（HWND 不变）变可见、标题 Windows，总数 1；
  - 再打开 System32 → 按「新窗口打开」新建第二个可见窗口（符合既有语义）；
  - 关掉窗口后 ZSDesk.exe 进程全部退出，不留看不见的常驻。
- 测试：`cargo test --workspace` 全绿（app 118 / core 22 / ui 29 / windows 48）；
  新增 `silent_start_only_pairs_with_a_plain_window_launch`，改写登录命令断言。
